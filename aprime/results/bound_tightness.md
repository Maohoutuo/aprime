# 界的紧性检验（E2.1/E2.2，抽象实例）

实例数 106；`universe=8`、`w=3`、`m∈2,3`。

**引理 2 有效性**：α_min > α_true 的实例 **0/106**（>0 就说明这条下界不成立）。

**对照经典 matroid 贪心的 1/2 界**：`α²(1−e^−α) = 0.5` 在 α₀ = 0.9137，所以 **α < 0.9137 时我们这套界比 1/2 还差**。

| 候选界 | 形式 | 违例数 |
|---|---|---|
| `b_classic_half` | 1/2（经典） | **0** / 106 |
| `b_true_sq` | α_true²(1−e^−α) | **0** / 106 |
| `b_true_half` | α_true(1−e^−α)/2 | **0** / 106 |
| `b_min_sq` | α_min²(1−e^−α) | **0** / 106 |
| `b_min_half` | α_min(1−e^−α)/2 | **0** / 106 |
