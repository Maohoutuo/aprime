# 跨尺度复核：哪些结论是伪影

*`experiments/compare_cross_scales.py` 生成；对比 **small/60** 与 **medium/60**。*

所有数值都是相对「全合成」基线的差（覆盖类为相对比例），故可跨尺度比较。
括号内是 **z 值**（效应 / 标准误）；|z| ≤ 2 表示该效应与 0 无法区分。

判定顺序：先看显著性 → 再看方向 → 再看量级。
* 任一尺度不显著 → **不显著（噪声级）**；
* 两尺度都显著且异号 → **反转**（至少一次是伪影）；
* 同号且相对差 ≤ 50% → **复现**；同号但差更多 → **仅方向复现**。
