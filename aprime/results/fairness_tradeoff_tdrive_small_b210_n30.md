# 主权衡图数据（tdrive/small，N=40，k=8）

生成脚本 `experiments/run_fairness_tradeoff.py`。`cov/预算` 是覆盖率占预算步数的比例；`excl` = 低能力组被排除率 − 高能力组被排除率（负值说明低能力者更容易被排除）；`cfi` = 名额份额与**能力**份额的最大偏差（东华 CFI 型口径）；`gqc` = 名额份额与**人数**份额的最大偏差（我们的口径）。**两者按设计互相冲突**：GQC 压 `gqc` 必然抬高 `cfi`。

> **`gqc` 的可读性取决于分组**：`组数 = 1` 时它恒为 0（标 **退化**，该格不可用于任何差距比较）；`最低组份额` 带 `†` 表示低于 15%（E5.2 门槛）——这通常反映**人群结构**（低能力者本就只占一成），不是估计精度问题，但意味着该组的名额分配分辨率有限，解读时要结合下面的置信区间。见 docs §8.7–8.9。

**`ks` / `rank` 是不分桶的替代度量，不受分组退化影响**：`ks` = 选中者能力分布与合法池能力分布的 KS 距离（0 = 分布一致）；`rank` = 选中者能力百分位均值相对池中心 0.5 的偏移（负 = 偏向低能力者，正 = 偏向高能力者）。实测二者跨种子噪声低于 `gqc`，推荐作为主报告量。
