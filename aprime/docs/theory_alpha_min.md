## 0. 记号

* `U` 参与者集合，每个 `u` 有一族候选路线 `R_u`（本文实现取 `|R_u| = k = 12`，与 θ 无关）。
* `cells(r) ⊆ [n_x] × [n_y]`：路线的**空间**栅格覆盖集（方案 §2.1 的"栅格单元总数"）。
  ⚠️ 不要用 `(x, y, t)`：Day-1 实测表明按时空三元组计覆盖会退化成"填满预算"（见 §7）。
* `S_u(r)`：满意度（复用 MAPUS 的 PSS 标定 `a·cos(p_u,h(r)) − μ·risk(r)`，见
  `mapus/docs/calibration.md`）。
* 合法元素集 `E(θ) = {(u, r) : r ∈ R_u, S_u(r) ≥ θ_u}`。
* 可行解族 `I(θ) = { Ω ⊆ E(θ) : 每个 u 至多一条, cost(Ω) ≤ B }`，
  `cost` 取步数（默认）或人数（`APrimeConfig.budget_kind`）。
* 目标 `f(Ω) = |∪_{(u,r)∈Ω} cells(r)|`。

## 1. 引理 1（单调 + 次模）

`f` 在 `E(θ)` 上单调不减且次模：对任意 `S ⊆ T`、`e ∉ T`，
`f(S∪{e}) − f(S) ≥ f(T∪{e}) − f(T)`。这是覆盖函数的经典性质（每个新元素贡献的是"尚未覆盖的格子"）。

推论（下面反复用）：`f(S∪T) − f(S) ≤ Σ_{e∈T\S} [f(S∪{e}) − f(S)]`。

## 2. 次模比 α 的定义（与代码一致）

```
α_f(θ) = min_{S, T}  [ f(S∪T) − f(S) ] / Σ_{e∈T\S} [ f(S∪{e}) − f(S) ]   ∈ (0, 1]
```

分母仅在"存在正增益"时取（`aprime/analysis/submodularity.py` 已按此实现采样估计）。

* `α = 1` ⇔ 在所取样本上 f 对 T 内元素"无额外损失"（路线之间不重叠）；
* `α < 1` ⇔ 显著冗余（路线重叠）；
* α 只依赖 `(实例, θ)`，与算法无关，因此可以当作"问题的属性"画进 Fig.3 / Fig.6。

## 3. 引理 2（α 的闭式下界）——**降级为猜想**：推导有洞，但打不穿

设对任意 `e, e' ∈ E(θ)`：`|cells(e) ∩ cells(e')| ≤ ρ(θ) · min(|cells(e)|, |cells(e')|)`
（**重叠系数**口径，不是 Jaccard），`m = |E(θ)| = max_{S,T} |T \ S|`。猜想：

```
α_f(θ) ≥ α_min(θ) := 1 / ( 1 + (m − 1) · ρ(θ) )
```

**能证的部分（带 γ 的版本）**：记 `A_e = cells(e) \ covered(S)`、`a = Σ_{e∈T}|A_e|`，
并令 `γ = min_{S,T,e∈T} |A_e| / |cells(e)|`（"还没被盖住的那部分占比"的下界）。则

```
α_f(θ) ≥ 1 / ( 1 + (m − 1) · ρ(θ) / γ )
```

*证明*：由 Cauchy–Schwarz 型并集下界 `|∪_{e∈T} A_e| ≥ a² / Σ_{e,e'∈T}|A_e ∩ A_e'|`；
对角项和恰为 `a`，非对角项 `|A_e∩A_e'| ≤ |cells(e)∩cells(e')| ≤ ρ·min(|cells(e)|,|cells(e')|) ≤ (ρ/γ)·min(|A_e|,|A_e'|)`，
故分母 `≤ a + (ρ/γ)(m−1)a`，比值得证。∎

**缺的那一步（为什么只能叫猜想）**：原写法默认 `γ` 可以取 1（即"没被覆盖的部分仍然占整条路的固定比例"），
这一步**不成立**：`S` 可能已经把某条路线盖掉 99%，此时 `γ ≈ 1/|r|`，界会掉到 `1/(1+(m−1)ρ|r|)`。
打穿它需要"路线两两重叠小"+"`A_e` 又都很小且重合"同时成立，而这两种要求在几何上互相拉扯。

**为什么它至今没被反例打穿（0/106，含一个刻意构造的压力例）**：
"取最坏重叠系数"这一步本身就惩罚嵌套——只要有一条路线**包含**在另一条里，`ρ_oc` 立刻等于 1，
`α_min` 掉到 `1/|E|`，于是想打穿它就得同时避开嵌套，而这恰好堵住了 `γ` 变小的通道。
压力例 `crafted:nested_cover_stress`（`results/bound_tightness.md`）：
按"`α ≤ 1/m`"的直觉该违例，实测 `α_true = 0.250`、`α_min = 0.125`，**反而更保守**。

两端点仍然正确：`ρ = 0` ⇒ `α_min = 1`；`ρ = 1` ⇒ `α_min = 1/m`，
与 `tests/test_aprime.py::test_alpha_drops_with_redundancy`（m=4 时 α=0.25）一致。

### 3.2 致命判定：成对重叠路线**两头堵**（Day-3 结论，务必看）

> 补充（Day-5）：§3 的引理本身只能算**猜想**（推导缺 `γ` 条件，见 §3 正文）。
> 这不影响本节的结论——本节说的是"界即便成立也太松"，比"界是否成立"更强。

我把 §3.1 的"换个 ρ 口径再试"做成了可判定的实验（`experiments/run_bound_tightness.py`，
104 个小实例，`α` 用**精确枚举**算，见 `aprime/analysis/alpha_exact.py`）。结果连错两次，
第二次的错法是结构性的：

**第一次错（已修）**：ρ 用了 Jaccard（交/并）。引理推导要的是
`|A∩B| ≤ ρ·min(|A|,|B|)`，所以必须是**重叠系数**（交/min）。用 Jaccard 会算出
`α_min > α_true`（`crafted:identical`：α_min=0.5 > α_true=1/3）。

**第二次错（结构性的）**：`m` 用了 `⌊B/min|r|⌋`。但 α 的定义里 `T` 是 `E(θ)` 的**任意子集**，
不受预算限制，所以正确的 `max|T\S| = |E(θ)|`。用预算截断后：

| 写法 | 引理 2 是否成立（α_min ≤ α_true） | 得到的 α_min（真实实例） | 有用吗 |
|---|---|---|---|
| `m = ⌊B/min|r|⌋` | **不成立：70/104 个实例违例** | 0.17–0.24 | 无效 |
| `m = \|E(θ)\|`（唯一合法） | 成立：0/104 | **0.004–0.16**（`\|E\|=240`、`ρ_oc≈0.6` ⇒ ≈0.007） | 空界 |

两头堵 ⇒ **成对重叠这条路走不通**。更糟的是第三个数：

**公式本身也被经典结果支配**：`α²(1−e^{−α}) = 1/2` 的解是 **α₀ = 0.9137**。
也就是说，只有 α > 0.914 时这套界才比"划分拟阵 + 单调次模的贪心 1/2"更好；
而实测 `α_true` 在 104 个实例上的中位数只有 **0.333**（最大 1.0）。
所以在这批实例里，**我们辛苦推的 α 界从未打赢直接引用 1/2**。

顺带记一笔：`b_true_sq`（用真 α 的公式值）在 104 个实例上**零违例**（最坏 `r=0.571` vs
bound 0.014；`α_true=0.778` 时 bound 0.327 vs `r=0.833`）。所以公式**没有被证伪**，
只是"正确但无用"——这在评审里比错更尴尬：证明了却没人能用。

→ 决策见 §5.5（已采纳：正文用与 θ 无关的 1/2，α 曲线降级为附录下界 + 实证诊断）。

## 5. 定理 2（定稿措辞）：与 θ 无关的保底保证

### 5.1 定理陈述（可直接进正文）

记 `f(Ω) = |∪_{(u,r)∈Ω} cells(r)|`，可行域
`I(θ) = { Ω ⊆ E(θ) : 每个 u 至多一条, cost(Ω) ≤ B }`。

> **定理 2（保底保证）** 设 `I(θ) ≠ ∅`。
>
> **(a) 基数口径**（`cost(Ω) = |Ω| ≤ B_c`）：对任意 `θ ∈ [0,1]`，
> A′ 的输出满足 `f(Ω) ≥ ½ · max_{Ω'∈I(θ)} f(Ω')`。
>
> **(b) 步数口径**（`cost(Ω) = Σ steps(r) ≤ B`）：`f(Ω) ≥ ½(1 − 1/e) · OPT(θ)`，
> 其中 `OPT(θ) = max_{Ω'∈I(θ)} f(Ω')`，常数对满足 `max_r steps(r) ≤ B` 的任意实例成立。
>
> 两式中**常数与 `θ`、`φ`、`ρ` 无关**。

**英文版（投稿直接用，与上式逐字对应）**

> **Theorem 2.** Let `I(θ)` be non-empty.
> **(a)** If the budget is a cardinality bound `|Ω| ≤ B_c`, then for every `θ` the output of A′ satisfies
> `f(Ω) ≥ ½ · OPT(θ)`.
> **(b)** If the budget is a travel-step bound `Σ steps(r) ≤ B`, then `f(Ω) ≥ ½(1 − 1/e) · OPT(θ)`
> for every instance with `max_r steps(r) ≤ B`.
> In both cases the constant is independent of `θ`, `φ`, and the overlap ratio `ρ`.

**成立条件（正文逐条点名，缺一不可）**

| 编号 | 条件 | 依据 |
|---|---|---|
| H1 | `f` 单调不减且次模 | 引理 1（覆盖函数的经典性质） |
| H2 | 每人至多一条 ⇒ 划分拟阵；基数预算 = 其 `B_c`-截断，**截断仍是拟阵**（截断的秩函数 `r'(S) = min(r(S), B_c)` 仍是秩函数） | Oxley, Matroid Theory, 2nd ed., Oxford University Press, 2011, §1.2（截断/truncation）〔定理号待核〕 |
| H3 | 步数口径下把边际换成密度 `Δf/steps`；**纯密度贪心**给 `½(1−1/e)`（`1−1/e` 需要部分枚举，我们不用） | Khuller, Moss & Naor (1999), The budgeted maximum coverage problem, Information Processing Letters 70(1):39–45〔定理号待核〕 |
| H4 | `I(θ) ≠ ∅` | §5.2 的可行性单调性 + `θ_any` 闭式 |

> **引用状态**：R1（截断保拟阵）、R2（KMN 常数与"多一条划分拟阵能否照搬"）已由 A 复核通过。

> 已标注为〔定理号待核〕，不编造**。排版时按 A 的版本补充定理号即可，无需改正文措辞。
> 两点 A 认可的论证已并入正文：① 我们比原文多一条划分拟阵，但 KMN 的分析只用到
> "次模性 + 代价可加 + 单元素代价 ≤ B"，加约束只缩小可行域，分析逐行照搬；
> ② `max_r steps(r) ≤ B` 这个前提**可能冗余**（超预算的路线本来就不可选），
> 保守起见暂保留，定稿时可去掉改成"对任意实例成立"。

**证明骨架（三步，每步都只引用标准结果）**

1. **θ 只收缩可行域**：`F_u(θ) ⊆ R_u` ⇒ `I(θ) ⊆ I(0)`；`f` 本身不含 θ。
   所以下限只要对"某个可行实例"成立，就对所有 θ 成立 —— 这是常数与 θ 无关的全部原因。
2. **(a)** `I(θ)` 是划分拟阵的 `B_c`-截断（截断保拟阵），故是拟阵；对拟阵约束下的单调次模最大化，
   边际贪心满足 `f(Ω_greedy) ≥ ½ OPT` → Fisher, Nemhauser & Wolsey (1978), An analysis of approximations for maximizing submodular set functions — I, Mathematical Programming 14(1):265–294〔定理号待核〕
   A′ 的主干就是边际贪心；局部搜索只接受**严格改进**的移动（`greedy.py::local_search` 里是
   `cov > cur_cov` 才换），因此 `f(A′) ≥ f(纯贪心)`，**不会破坏**该下界。
3. **(b)** 约束变为背包，非拟阵；按密度贪心的标准分析给出 `½(1 − 1/e)` → Khuller, Moss & Naor (1999), The budgeted maximum coverage problem, Information Processing Letters 70(1):39–45〔定理号待核〕，同样"只改进"论点给出 A′ 的界。

**三条必须在正文（footnote 即可）说明的备注**

* **R1 常数不紧，别拿它当卖点**：Day-4/5 实测 `A′/OPT = 0.945–0.975`（T-Drive small）。
  这个界的作用是"任何实例都不会崩"，不是"我们接近最优"。
* **R2 `½` 是"每人一条"的代价**：去掉划分拟阵、只留基数约束时，常数可提到 `1 − 1/e`。
  论文要明说这一点，否则审稿人问"为什么不是 `1−1/e`"时无从回答。
* **R3 θ 不进常数是优点**：说明个性化**不削弱**最坏情形保证；个性化的代价在可行性与经验覆盖
  （§5.2），不在近似比。

### 5.2 θ 的真实作用：可行域与可行性（**替换**原"APX(θ) 单调性"）

> **命题 4（可行性单调 + 两个闭式阈值）** 记 `U⁺ = {u : R_u ≠ ∅}`（候选池非空的参与者）。
> 对每个 `u`，`F_u(θ) = {r ∈ R_u : S_u(r) ≥ θ_u}` 关于 θ 单调不增；
> 因而 `E(θ)`、`I(θ)`、`OPT(θ)` 都单调不增。定义
>
> ```
> θ_all = min_{u∈U⁺} max_{r∈R_u} S_u(r)        θ_any = max_{u∈U⁺} max_{r∈R_u} S_u(r)
> ```
>
> 则：`θ ≤ θ_all` ⇔ **每个**参与者都至少保留一条合法路线；
> `θ > θ_any` ⇔ `I(θ) = ∅`（问题彻底不可行）。
> 两个阈值都可**显式算出**，无需搜索。

> ⚠️ 必须限定在 `U⁺` 上：若某个 `u` 的 `R_u = ∅`，`max_{r∈R_u} S` 是 `−∞`，
> `θ_all` 会退化成 `−∞`，命题就没意义了。当前数据管线不会产生空池
> （`candidates.py::build_candidates` 为每个 worker 至少留一条），但正文必须写 `U⁺`。

⚠️ **这两个阈值别搞混**（Day-5 我自己写错过，被 `tests/test_aprime.py::test_theta_thresholds_closed_form` 抓住）：
"所有人都还有得选"是 `min_u`，"还有人能选"是 `max_u`。它们夹住的区间 `(θ_all, θ_any]`
正是**越来越多参与者被结构性排除**的区间 —— Day-4 的 `feasible_rate(θ)` 曲线就是在这段上从 1 掉下来。

**经验事实（Day-4，`results/fairness_tradeoff_tdrive_small.md`）**：θ: 0 → 0.9 时
覆盖只降 5.6%（0.975→0.920）、PSS 升 30%（0.751→0.974），但**可行率从 1.000 掉到 0.620**。
所以 Fig.3 画两条线：`feasible_rate(θ)` 与 `coverage(θ)`，**不再画 APX(θ)**。

**明确删除的主张**（写进 limitation，避免审稿人按老版本提问）

* ✗ `APX(θ)` 关于 θ 单调 —— 界本身是空的（§3.2）；
* ✗ `dα/dθ` 的绝对值随 `φ̂_cos` 增大 —— 合法 `m` 下测不出来（0.007–0.021，无方向）；
* ✗ `θ*` 随 φ 左移 —— 加密网格后峰值都在 θ≈0.50，且系数不显著；
* ✗ α(θ) 改善近似比 —— 交叉点 α₀ = 0.9137，实测 α_true 中位数 0.333。

### 5.4 附录 A：α 型附加下界（正确，但通常弱于 `½`）

> **命题 5（附加下界）** 若 `α = α_f(θ)` 为精确次模比，则贪心满足
> `f(Ω) ≥ α²(1 − e^{−α}) · OPT(θ)`。

* **有效性**：104 个精确枚举小实例上，该式**零违例**（最坏 `r=0.571` vs bound 0.014；
  `α_true=0.778` 时 bound 0.327 vs `r=0.833`）；Lemma 2 在唯一合法口径（`m=|E(θ)|`、
  重叠系数）下 `0/104` 违例。见 `results/bound_tightness.md`。
* **但它通常无用**：只有 `α > 0.9137` 时才强于 `½`，而实测 `α_true` 中位数 0.333。
* **允许的用途**：附录里给"实例相关证书"（`α̂` 可采样、可复算），以及 §E2.3 的难度诊断；
  **禁止**在正文把它写成"个性化强度 → 近似比"的定理。

## 6. E2.2 紧性构造（已由枚举实验替代，结论：不需要构造）

原计划是手造一维实例扫 `(k, ρ, w)` 逼近界。Day-3 直接做了更彻底的事：
枚举 104 个抽象小实例 + 4 个手工端点（不重叠 / 完全重叠 / 贪心经典失效 / 划分拟阵挤压），
对每个实例算**精确 α**、**精确 OPT**、纯贪心，再逐条检验四个候选界是否被违反。

结论（`results/bound_tightness.md`）：所有候选界零违例，但最坏的实测比值 `r = 0.571`
（`ρ_oc = 1.0`、`α_true = 0.25`）对应的界只有 0.014 —— **松 40 倍**。
所以"构造一个把界逼紧的实例"这件事已经没有意义：**界在任何实例上都松**，
它的瓶颈是 `α` 本身的定义方式（全局 min 被极值主导），不是某个构造。
这条负结果记为 E2.2 的最终答案，不再单独占一节论文篇幅。
