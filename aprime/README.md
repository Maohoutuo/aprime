## 三个必须记住的口径决定

1. **覆盖按空间格子 `(x,y)` 计，不按 `(x,y,t)`。** 按时空三元组计时，不同参与者的时间轴几乎不
   重合，覆盖恒等于步数预算、`A′ = exact = random = SA`，θ-曲线完全退化（Day-1 实测踩过）。
2. **候选池与 θ 无关**：一次生成、θ 扫 10 档全程复用（方案 §7.4 的省 60% 成本就是靠这个）。
   θ 只在 `SelectionProblem.eligible` 处生效，算法本身对 θ 无感知。
3. **预算两种口径都实现**：`steps`（默认，与论文表 1 的 40/60/100 一致）与 `count`（方案原文写法）。
   注意定理 2 的干净式子只在基数预算下成立，步数预算会多一个背包因子（见理论草稿 §5）。

### Day 2：α 议题的实证支撑（密度 × 偏好同质性）

W1 剩下的未知是"θ↑ → 冗余↑ → α↓"到底有没有实证。做了两次对照实验：

| 实验 | 杠杆 | 结果 |
|---|---|---|
| `run_density_stress.py` | 参与人数 20→320（同栅格/同预算/同时间窗） | **负结果**：ρ 稳定在 0.056–0.072、覆盖仍贴满预算。人多 → 候选池更**多样** → 贪心更容易挑出不重叠的路线。**密度不是杠杆** |
| `run_pref_homogeneity.py` | 偏好同质性 φ（向锚点 archetype 凸组合） | **弱正结果**（3 种子）：φ̂=0.999 时 ρ̄ 0.064→0.088、α_min 0.225→0.206；φ̂=0.564 时 α_min 0.232→0.227。方向对，但幅度在噪声带内 |

结论已写回 `docs/theory_alpha_min.md` §4：把"全程单调"降级成**临界阈值 θ\*(φ)** 的陈述
（只对 `θ ≥ θ*` 承诺单调）。加密网格后 θ\* 实测在 **≈0.50 且对 φ 不敏感**，所以
"θ\* 随 φ 左移"这条主张被**删掉**——它会被数据反驳。

### Day 2 最重要的发现：Lemma 2 的界是**空界**

给自己挑错挑出一条硬结论。Lemma 2 要的是**最坏**成对重叠，早期实现却用**均值** ρ 去算，
把界说强了。改成合法的 `ρ95` 后（`analysis/submodularity.py::overlap_stats`，
测试 `test_alpha_min_uses_worst_case_rho` 守着）：

| 量 | tdrive_small（n=3, k=12, B=40 步） |
|---|---|
| ρ̄（均值，只看趋势） | 0.061–0.093 |
| **ρ95（界该用的量）** | **0.239–0.333** |
| m = ⌊B / min|r|⌋（唯一合法的保守取法） | 15 |
| α_min | 0.172–0.237 |
| APX_min | **0.005–0.012** |
| **实测 A′/OPT** | **0.945–0.983** |

界比现实松**两个数量级**。这不是实现 bug，是"成对重叠"这条路线的固有损耗；
也不能靠把 m 换成中位数去救（那会让界失效）。给了 A 四条出路（`docs/theory_alpha_min.md` §3.1）：
小 m 的制度设定 / 换路线族结构引理 / 只承诺"保证存在" / **双轨写法（我建议先按这条起草）**。

**至今仍缺**：定理 2 的措辞改写（§5.4 已定方向）；MSCTA_Greedy 与东华版 SA 变体；
φ̂_cos 的跨数据集可比性。

### Day 3：判定实验——**成对重叠路线两头堵**

把 Day-2 的"界太松"做成了可判定的实验：`experiments/run_bound_tightness.py`，104 个抽象小实例，
`α` 用**精确枚举**（`analysis/alpha_exact.py`，`3^n` 全扫）而不是采样估计。连错两次，第二次是结构性的：

| 写法 | 引理 2（α_min ≤ α_true） | 真实实例上的 α_min | 判定 |
|---|---|---|---|
| ρ 用 Jaccard | 不成立（`identical`：0.5 > 1/3） | — | 口径错 |
| m 用 ⌊B/min\|r\|⌋ | **不成立：70/104 违例** | 0.17–0.24 | 无效 |
| **m = \|E(θ)\|（唯一合法）** | 成立：0/104 | **0.004–0.16**（`\|E\|=240` ⇒ ≈0.007） | **空界** |

第三个数字更致命：`α²(1−e^−α) = 1/2` 的解是 **α₀ = 0.9137**，而 104 个实例的 `α_true`
中位数只有 **0.333**（最大 1.0）——**这套界从未打赢直接引用经典的 1/2**。
同时 `b_true_sq` 零违例，说明公式本身没被证伪，只是"正确但无用"。

**决策（`docs/theory_alpha_min.md` §5.4）**：正文保证降级为 **1/2**（划分拟阵 + 单调次模，与被引标准结果一致）；
α(θ) 保留为"实例难度诊断"与 E2.3 实验分析；`θ*` 保留为**经验**可用性阈值。这样 4 个定理的结构变成
"可行性 NP-hard / 1-1/2 保证 / 公平性不兼容 / learning-augmented 双界"，比硬凑 α 更站得住。

### Day 4：公平性度量 + 主权衡图数据（论文真正的贡献层）

新增 `analysis/fairness.py` 与 `experiments/run_fairness_tradeoff.py`
（`results/fairness_tradeoff_tdrive_small.md`：T-Drive 40 人 / k=8 / 5 种子）。
**关键口径**：θ 一提高，很多人**根本没有**合法路线，所以必须把「可行」与「公平」拆开——
`feasible_rate` 报个性化的代价，`exclusion_gap` 只在**合法池**内算。不拆开的话，
高 θ 端会出现虚假的"更公平"（第一版实测 θ=0.9 时 `excl` 跳到 +0.30）。

三个能写进论文的结论：

1. **代价主要在参与机会，不在覆盖**：θ: 0 → 0.9 时覆盖只掉 **5.6%**（0.975→0.920）、
   PSS 涨 **30%**（0.751→0.974），但**可行率从 1.000 掉到 0.620**。
   这才是 `θ*` 的真实含义：参与资格上限，而不是近似比阈值。
2. **满意度硬约束本身是"内部均衡器"**：入选者 `gini_pss` 0.131 → 0.025（−81%）。
   这是 θ 的机制性后果，**不是算法优势**，论文里不能写成"我们更公平"。
3. **CFI 型指标没有区分度**（创新点 3 的直接动机）：θ=0.6 时各方法 `cfi_gap` 全在
   **0.141–0.180**，而 `exclusion_gap` 从 **−0.07 跨到 +0.24**；同时 CFI 型 capacity
   给出最高 PSS（0.883/0.940）却最低覆盖（0.770/0.740）、排除差最大（0.139/0.240）、
   还违反 θ 0.2–0.4 次 → "名义公平、实质挤出 + 违约"，E3.1 的靶子数据已就位。

### Day 5：定理 2 措辞定稿（§5.4 决策落地）

`docs/theory_alpha_min.md` 的 §5 已整节重写为**可进正文**的版本：

* **定理 2（定稿）**：(a) 基数口径 `f(Ω) ≥ ½·OPT(θ)`；(b) 步数口径 `f(Ω) ≥ ½(1−1/e)·OPT(θ)`；
  两式常数**与 θ、φ、ρ 无关**。中英双语 + 成立条件表 + 三步证明骨架 + 三条必写 footnote。
* **§5.2 换掉"APX(θ) 单调性"**：改为可行性命题，并给出**两个闭式阈值**
  `θ_all = min_u max_r S_u(r)`（所有人都还有得选）与 `θ_any = max_u max_r S_u(r)`（彻底不可行）。
* **§5.5 明确列出删除的主张**：`APX(θ)` 单调 / 斜率随 φ / `θ*` 左移 / α 改善近似比。
* **§3 的引理 2 降级为猜想**：原推导缺一个 `γ`（未覆盖占比）条件，补上后只能得到
  `1/(1+(m−1)ρ/γ)`。我专门构造了压力例想打穿它（`crafted:nested_cover_stress`），**没打成**——

### Day 6：创新点 3 算法——分组配额一致（GQC）

新增 `aprime/groups.py`、`aprime/solvers/gqc.py`、`docs/gqc_design.md`，并用
`experiments/run_fairness_tradeoff.py`（T-Drive small，100 对配对差值，±95% CI）验收：

* **设计**：能力按“合法路线条数 = 1 / 2 / ≥3”分三组；名额按**合法池内人数份额**分配，
  替代东华 CFI 型的“名额 ∝ 能力份额”。两套公平观**不可兼容**——GQC 压 `gqc_gap` 时
  `cfi_gap` 不改善（Δcfi +0.001，CI 跨 0），这正是创新点 3 要说的论点，不是缺陷。
* **vs A′**：Δgqc_gap **−0.025 [−0.037, −0.012]**、Δcov −0.16 [−0.30, −0.02]（≈0.4% 预算）、
  ΔPSS 不显著；`floor_ok` / `quota_ok` 命中率 **100%**、θ 违规 0。
* **vs 东华式基线**：GQC 同时**多覆盖 +0.96～+8.10 格**、`gqc_gap` 与 `exclusion_gap` 更低
  （gqc − capacity 的 Δexcl = **−0.214 [−0.247, −0.182]**），且 θ 违规 0 而它们违约 0.3–2.0 次。
* **一个设计 bug 被测试抓住**：上界若取 `floor+bandwidth`，三组各 floor=2、k=6 时会逼出违约解；
  改成“其余各组下界推出”的上界 `k − Σ_{f≠g} floor_f`，并把 catch-up 检验改成**求和**（Hall 条件）。

**未成立的主张**（诚实记录）：`exclusion_gap` vs A′ 的 CI 跨 0，N=120 扩容后仍不显著。
诊断：6 个名额落在 40–120 人池里，±1 个名额只值 ±0.017–0.025，**指标粒度不够**；
需要把预算提到 12–15 个名额（或把池子缩到 40–60 人）才能让结构效应显现。
