1. 复现了什么

  • 城市属性层：6 类土地利用（vegetation / industrial / institutional / medical / residential / commercial）与犯罪风险场，对应式 (3)(4) 与附录 B.1。
  • 参与者画像：5 个 archetype（生态爱好者 / 都市居民 / 产业工人 / 社区助手 / 探索者）， 含人口统计、爱好、经济状况与土地利用偏好向量，对应附录 B.2 与图 10。
  • PSS 指标：S(r)=a·cos(p_u,h(r_u)) − μ·risk(r_u)，对应式 (2)。
  • Participant Agent：接单决策 + 算法 1（TSPTW 可行基线 → LLM 迭代精修 → 可行性校验/投影）。
  • Coordinator Agent：算法 2（边际覆盖增益 + 公平分 + LLM 平局裁决）与算法 3（重叠配对协商）。
  • 对照组：RN / TVPG / TCPG / MSA / MSAGI / GraphDP 六个经典基线 + 单 LLM 一次性规划基线。
  • 实验：表 2/3 主结果、图 3 消融、表 4 协商统计、图 4 公平性、表 5 运行时、图 11 基座模型、图 12 扰动案例。

9. 与论文的已知差距

不可恢复的信息：原始 POI / 犯罪数据、E(D) 的分层熵定义（引自 Ji et al. 2016）、 式 (2) 的 μ、算法 1 的 λ、式 (6) 的 β、算法 3 的 τ/K/N、以及 T-Drive / Grab-Posisi 的原始轨迹均未公开。 本工程用「结构化合成城市 + 逐格配额抽样」生成土地利用，用同分布的合成移动性替代真实轨迹， 并对 PSS 的尺度 (a, μ) 与覆盖效用的 e_scale 各做了单参数/双参数标定（见 §8）。 因此绝对数值不可与论文逐格对齐，可比的是同一实现下的方法间相对关系与趋势。
